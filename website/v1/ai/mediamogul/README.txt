🎬 MediaMogul - OpenAI AI Studio for Shotcut (v1.0.0 Windows x64)
Zero External Dependencies - No Python or Pip Required!
========================================================================

✨ WHAT'S INCLUDED:
------------------------------------------------------------------------
1. Native Top-of-Screen Menu Item:
   Sits right next to "Help" on Shotcut's menu bar matching Shotcut's dark theme.
2. MediaMogul Agentic AI Command Center:
   Standalone desktop app (mediamogul_command_center.exe) with:
   - 🎖️ Commander Multi-Agent Swarm (Script, Timeline, Stylist, Audio & Reviewer Agents)
   - 🤝 Editor Collaboration Hub: Export single action logs, ultra-lightweight project packs (.zip) with system links (file:///) and NO heavy media, or turnkey master archives
   - ⚡ 50+ Autonomous Video Manipulation Capabilities (trimming, 9:16 vertical crop, silence detection, loudness normalization, audio ducking, speed ramping, transitions, etc.)
   - 🎙️ Whisper speech-to-text subtitles (.srt), OpenAI TTS narration, and DALL-E 3 B-Roll.
3. In-Editor Shotcut Filter (MediaMogul):
   Renders AI titles, lower thirds, captions, and translations directly onto
   video clips inside Shotcut with interactive on-screen drag handles.

🚀 1-STEP INSTALLATION:
------------------------------------------------------------------------
1. Double-click "install.bat".
   (It automatically copies the plugin to your Shotcut extensions folder).
2. Double-click "mediamogul_command_center.exe" (or "run_mediamogul_command_center.bat").
   If Shotcut is not running, click the green "🚀 Launch Shotcut" button!
3. On Shotcut's top menu bar, you'll see "MediaMogul" docked seamlessly next to "Help"!

⚙️ CONFIGURATION:
------------------------------------------------------------------------
In the Command Center or inside the Shotcut filter panel under "Settings",
paste your OpenAI API Key (sk-...) and click "Save Key".

Enjoy editing with AI in Shotcut!
