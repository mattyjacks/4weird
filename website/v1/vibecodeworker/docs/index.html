VibeCodeWorker manual

Use VibeCodeWorker to explore a game or website, collect evidence, and prepare a repair workflow. Start with a target and a small, observable goal.

Keep control of the run. Review the selected target, watch the live viewport, and stop the agent whenever the behavior is not what you intended.

1. Start at the Hub

The desktop app opens on the Hub. Choose the path that matches the work:

  • Load 4weird Games for the built-in HTML5 catalogue.
  • Test Any Website for a URL-based UX or form-flow audit.
  • Open Specific Folder for a local project.
  • Work on Desktop Game for a running Windows game such as a modded Skyrim installation.

2. Run a web or HTML5 playtest

01

Load a page or choose a game. Add a goal such as “check the main menu, movement, restart flow, and visible errors.”

02

Confirm the target in the viewport. Use Start AI Agent to begin. The action trail, screenshots, console context, and findings appear in the workspace.

03

Pause at any time. Save a replay or generate a repair prompt when you have enough evidence.

3. Work on a desktop game

Desktop-game mode is for supervised capture and input against one window you explicitly select.

01

Launch the game first and enter a safe scene. For Skyrim, use a disposable save and avoid menus that could make permanent changes.

02

From the Hub, choose Work on Desktop Game. The detailed options open and scan visible Windows game windows.

03

Select the exact game window. VibeCodeWorker captures that window and sends its clicks and keys only to that selected title.

04

Use a conservative goal: inspect menus, basic movement, camera behavior, NPC interaction prompts, or a repeatable route. Start the agent while watching the game.

For video: record the selected game with OBS or another recorder. VibeCodeWorker supplies the supervised playtest; your recorder creates the final footage.

4. Review, evidence, and repair

  • Snapshot captures a frame for the evidence stream.
  • Logs collect browser and playtest context.
  • Save Replay preserves the action sequence.
  • Generate Mega-Prompt packages target context, findings, and scanned code for a repair pass.
  • Run AI Coding Fix proposes a change; review it before applying it.

5. Troubleshooting

No desktop game appears: make sure the game has a visible, non-minimized window, then scan again.

Inputs reach the wrong place: stop the run, reselect the exact title, and ensure the game is foregrounded.

The agent has no useful target: pause it, reload the page or select the window again, then narrow the goal to one flow.

6. Good test goals

  • “Open the menu, change one setting, return to the game, and check controls.”
  • “Walk a short route, rotate the camera, and note frame drops or stuck movement.”
  • “Test the sign-up form for validation, keyboard navigation, and visible errors.”
