# DevSwarm Lanes — 4weird

Claimable work lanes for the 4weird project. Live app is `v2/vcw4w` (Next.js).
This directory (`v2/vcw4w/public/swarm/`) is served world-readable at
`https://4weird.com/swarm/*`. **NEVER write secrets, keys, tokens,
credentials, emails, or any private data in this directory.** Markdown and
light JSON only.

`old-v1/` is a **read-only mirror** and is **explicitly unclaimable**: never
create, edit, or output anything under it. Lane agents may read it for
parity reference only.

## Shared-manifest rule (G10/E20 pattern)

- A lane agent works **only inside its lane's scope paths** below.
- Lane agents create **NEW files** in their scope. They do **not** edit
  shared manifests (catalog indexes, nav, sitemap, schema snapshots,
  package/config files).
- Anything needing a shared-manifest change is filed as a **QUEUE.md wiring
  request**; only that lane's **integrator** edits the shared manifest.
- Typical shared manifests (non-exhaustive): `v2/vcw4w/content/games.ts`,
  `v2/vcw4w/content/game-manifests.ts`, `v2/vcw4w/lib/site-nav.ts`,
  `v2/vcw4w/app/sitemap.ts`, `v2/vcw4w/app/robots.ts`,
  `v2/vcw4w/app/manifest.ts`, `v2/vcw4w/public/games/index.html`,
  `v2/vcw4w/supabase/schema.sql`, `v2/vcw4w/package.json`,
  `v2/vcw4w/package-lock.json`, configs (`next.config.ts`,
  `tailwind.config.ts`, `tsconfig.json`, `vercel.json`,
  `eslint.config.mjs`, `postcss.config.mjs`, `components.json`),
  `v2/vcw4w/public/swarm/QUEUE.md` (if present).
