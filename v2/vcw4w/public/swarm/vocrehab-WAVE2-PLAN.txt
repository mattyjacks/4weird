3. 3 DIFFICULTIES (persona + strictness scale, encouraging copy)
================================================================
- BEGINNER "Patient Coach" (warm, unhurried): simple behavioral Qs, no jargon, rephrases freely,
  0 curveballs, never interrupts, gives hints, accepts partial answers. Pass >= 60 (0.8x strictness).
- ADVANCED "Brisk Professional" (friendly but businesslike): STAR probing ("what was the RESULT —
  numbers?"), moderate technical depth, 1 curveball/session (gap, weakness), interrupts ONLY to
  redirect rambling ("Let me pause you there — the result?"). No hints, demands STAR example.
  Pass >= 70 (1.0x).
- EXPERT "Stern + Technical" (formal, terse, high standards): deep behavioral + technical + stress
  Qs (conflict, failure, tradeoffs), 2-3 curveballs/session (pushback, silence, "convince me"),
  may interrupt once to test poise; respectful, never personal. Challenges vague claims, scores
  concision (clarity <= 45 words). Pass >= 80 (1.25x).
- Same rubric axes all tiers; only thresholds/tone scale. Same 60-word/1-question-per-turn cap
  (45 for Expert). Progression: Beginner always open; Advanced unlocks after 1 Beginner pass;
  Expert after 1 Advanced pass — retries unlimited, tiers never lock out.
- Copy: "Ready for a bigger challenge?" / "Advanced unlocked — nice reps!" /
  "Expert is spicy — try it when you want. No score defines you." Never "failed / too easy".
- BINDING GUARDRAIL (all tiers): feedback targets phrasing choices ONLY — never accent, dialect,
  speech pattern, disability, or voice. Applies to personas, curveballs, interruptions.

4. MODES: LIVE vs TURN-BASED x SPEAK vs TYPE (all 4 valid)
================================================================
Default: Turn-based + Type (cheapest, calmest). Toggle per-turn; Send NEVER gated on mic/TTS state.

 LIVE-FULLY (realtime + barge-in): mic streams via SpeechRecognition interim ->
   mergePartialTranscript() -> live draft; coach TTS via speechSynthesis (or metered OpenAI).
   Typing any key cancels TTS (= text barge-in); Send interrupts same as voice.
   Barge-in protocol: VAD event "started" while speaking -> (1) speechSynthesis.cancel() + stop
   STT-streaming, (2) buildInterruptionSnapshot({partialUserText, coachSoFar, jobId+difficulty}),
   (3) next POST prepends snapshotToPrompt/resumptionPrefix ("[barge-in]...continue, don't restart").
   Interrupted turns tagged, count toward 6-turn cap, single queued-turn voice-wins. Noisy toggle ->
   threshold 0.05/12 frames + manual-send. pruneHistoryWithInterruptions(...,8).
 TURN-BASED (take your time): no VAD, no timer, no auto-submit. Mic dictates into composer only;
   edit freely, Send when ready. send() does stopListening() then POST.
 TYPE INSTEAD OF SPEAKING: always available in both session modes. Full keyboard path
   (Tab+Enter/arrows, no positive tabindex). Mic unsupported -> button disabled +
   "typing works fully". speak() try/catch — text reply always stays visible.
 TEXT PARITY: every voice turn renders as chat text (aria-live). Voice never POSTs audio.

5. GRADING + HOW TO IMPROVE (AI report card)
================================================================
Per-turn TurnGrade: {turn, praise, tweak, invitation, scores:{clarity, example, roleFit,
professionalism, disclosure}, weakTurn:bool}. Axes 1-5:
 clarity (<=60w grade 6-8; Expert <=45w), example (STAR: Situation/Task/Action/Result),
 roleFit (names skill tied to role), professionalism (no blame/slang),
 disclosure (pivot: 1 neutral line + forward; disclosure: owns choice, no identifiers; prep: blocklist-clean=5).
End-of-session report card (POST /roleplay/grade or computed at done=true): averages per axis,
overall 1-5 mean, grade A-F, verdict pass|retry, weakTurns[]. Pass = overall >= tier threshold
AND disclosure >= 3 AND zero blocklist hits. 6-turn cap triggers card + warm wrap-up.
How-to-improve per weak turn (score <= 2): one modelRewrite (<= 2 sentences, scenario-shaped:
 prep "I... result was..."; pivot "That period... since then... today I..."; disclosure
 "It helps to have... that helps me...") + one drill ("30-sec STAR retell", "3-sentence pivot rep",
 "1-sentence accommodation rephrase"). Reuses existing tweak (one rewritten sentence, never a
 command) + invitation retry. Difficulty scales strictness only; rubric/blocklist invariant.
Fail-open (LLM offline): reply = vocrehabRoleplayFallback(turn-1), feedback = rubric heuristics,
 offline:true. Scripted scores: clarity = words<=60?5:2; example = action+result words?4:2;
 disclosure = blocklisted?1:5; roleFit/professionalism default 3. Never throws; badge
 "Practice script — provider offline".

10. PROS AND CONS OF THIS FINAL PLAN
================================================================
PROS:
 + Best-of-4 synthesis: keeps Agent-1 ground truth, Agent-5/8 spinoff-safe engine placement,
   Agent-7 flat-file rip-out rule, Agent-6/9 content, Agent-10 DB/privacy verdict. No reinvention.
 + Spinoff-safe by construction: one-way deps, flat lib/vocrehab-*, shared engine survives rip-out.
   Copy-list is explicit (dirs + file counts + env swap).
 + $0 entry path: typing + turn-based + local TTS works fully with zero coins, zero mic, zero key.
   Metering only touches live/server-TTS legs at the standard 25%-included margin — no new economy code.
 + No new table: one migration (enum + metadata jsonb) reuses sessions/turns + documents path.
   Admin-save is explicit-consent only; ephemeral default preserves current privacy guarantee.
 + 20 jobs x 3 difficulties x 2 session modes x 2 inputs = real practice breadth without content
   explosion (Q1-4 shared frame; only Q5/follow-ups/curveball per job; difficulty = prompt clause +
   strictness multiplier, not new content).
 + Accessibility + guardrails baked in (captions, Esc-stop, reduced-motion, text parity,
   never-grade-accent/disability), not bolted on. Verifier slices make it enforceable.
 + CHEAP-executable: 10 one-file scopes, NEW-files-only, integrator-last — minimal collision with
   in_progress VocRehab lanes (C3/C4/C6/C7/V1/V3/V6) and open V2/V4/G1-G10.

CONS / RISKS:
 - Browser STT variance: Web Speech accuracy/noise differs by browser/locale; VAD thresholds
   (0.02/8) need the noisy-toggle fallback (0.05/12 + manual-send) and full type-parity, or live
   mode frustrates users with accents, stutters, or cheap mics.
 - No true full-duplex: browser-only barge-in is ~half-duplex (cancel + resume), not Realtime
   (~200-500ms). Interruptions feel abrupt; TTS boundary tracking is approximate. Upgrade path
   exists but costs $$/$$$ and new latency work.
 - Grading subjectivity: LLM rubric scores drift; strictness multipliers are heuristic until
   calibrated against counselor review. Fail-open scripted scores are crude (keyword/length).
   Needs a counselor spot-check loop before "grades" carry weight with admins.
 - Coin friction: even small per-session prices (~5-12 coins) may deter the exact users vocrehab
   serves. Mitigate with free turn-based default + clear pre-start price + first-session-free.
 - Scope creep surface: 20 jobs + 3 personas + 2 modes + grading + save + docs + verifiers is a
   lot for CHEAP (no retries). Wave discipline (1-file scopes, integrator-last) is load-bearing;
   any lane touching shared manifests early will collide.
 - Admin data sensitivity: saved transcripts + report cards become reviewable records. Requires
   consent copy, retention/export allowlist, and counselor-training note (scores = practice signal,
   not hiring decision) — otherwise misinterpretation risk.
