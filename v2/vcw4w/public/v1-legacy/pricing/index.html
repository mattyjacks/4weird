VIBECODEWORKER

Choose the infrastructure that fits the work.

Every path is built around the same testing and evidence workflow. The difference is where the API key and runtime come from.

01 · BRING YOUR OWN KEY

BYOK

Free for qualifying open-source projects

Use your own provider key while building in public.

  • Free for public open-source GitHub projects.
  • Also free where monetization is limited to no-pressure, non-required donations that never remove features.
  • Commercial or privately hosted code requires a paid user license.

02 · HOSTED KEYS

4weird Hosted Keys

API cost + 10% hosted-key premium

Use 4weird-managed provider keys instead of bringing your own.

  • A 10% premium is added to the API cost.
  • Planned to be operated through LiteLLM ↗.
  • Best when you want a simpler key setup and consolidated metering.

03 · FULLY MANAGED

4weird Managed Cloud

Cost + 15% managed-run premium

Use 4weird keys and run VibeCodeWorker on a virtual machine we provide.

  • 15% premium on virtual-machine, GPU, and API costs.
  • Designed for teams that want managed compute as well as managed keys.
  • Usage remains itemized so infrastructure costs stay visible.

PRIVATE & COMMERCIAL BYOK

Private & Commercial License

$10 per user / month

For privately hosted code on GitHub or elsewhere, with full commercial use. Your first month is $5 (50% off).

Metered BYOK use also adds 5% of API costs. API-cost telemetry is tracked and sent to 4weird for billing.

TEAM METERING CHOICES

Decide how API costs are handled.

Tracked Team

Tracked API costs for teams that want standard usage metering and cost visibility.

Untracked Team

$99 per user / month

Untracked API costs for teams that do not want API-cost usage sent to 4weird for metering.

Team metering is a planned account choice. The applicable VibeCodeWorker route, licenses, and infrastructure usage are shown separately at checkout.
