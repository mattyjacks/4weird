☁️ CLOUD SAVES

Your run is backed by 4 account-bound cloud slots (0–3). Sign in once and the same slots follow you between mobile and desktop in the same session — start stocking fridges on your phone, keep going on your PC.

🔄
Slots 0–3, shared everywhere
Mobile ↔ Desktop
Read a slot from any device with /api/saves?game=fridgesimulator&slot=N while signed in.

Reads: GET /api/saves?game=fridgesimulator lists your saves; add &slot=N (0–3) to fetch one slot. Writes: PUT /api/saves with { "game_slug": "fridgesimulator", "slot": N, "schema_version": 1, "data": {…} }. Saves are keyed to your account, so slot 2 on mobile is slot 2 on desktop. You must be signed in (signed-out reads get a 401).

🛡️
Slot 0 is the safety slot
Cheat-proof canon run
Keep your legit best run in slot 0 — the server strips cheat markers from it.

Slot 0 can never be marked cheat-moded: any cheat marker sent with a slot-0 save is stripped server-side (enforced again by a database trigger for non-API writes). Cheat marks on slots 1–3 are irreversible — a later save cannot erase them. Cloud saves cannot be deleted or reset from the client, so a cheated slot stays visibly cheated.
