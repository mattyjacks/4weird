# GraveGain2dB Acceptance Checklist

Manual playtest gate for `gravegain2dB` (Breach MoonRock). Every box is
checked by a human playtester; the automated bundle/DoD verifiers
(`scripts/verify-gravegain2dB-bundle.mjs`,
`scripts/verify-gravegain2dB-dod.mjs`) cover files/slug/purity/saves, this
doc covers feel.

## Onboarding

- [ ] Onboarding completes in under 60 seconds (menu -> hub -> mission select -> deploy, no help needed).

## Combat feel

- [ ] Destruction (mission 1): breaching the first sealed tunnel feels destructive — debris, shake, and audio all fire.
- [ ] Cautious play is approximately as viable as destructive play (cautious ≈ destructive clear times on the same mission).

## Co-op verbs

- [ ] Revive: a downed teammate can be revived mid-run.
- [ ] Rescue: a pinned teammate can be rescued from debris/collapse.
- [ ] Extract: the squad can extract together once the objective is done.
- [ ] Reconnect: a dropped player can reconnect and rejoin the live run.

## Readability

- [ ] Kid readable: a kid playtester can read every HUD objective without help.
- [ ] 4p legible: with 4 players on screen, every breacher stays legible (silhouette + nameplate, no visual mush).
- [ ] Solo fun: mission 1 is fun solo — no co-op required to enjoy the run.
