Desktop app required. This page is the UI of the 4weird-api-key-manager.exe Tauri app. Opened in a plain browser it cannot reach the OS credential store, so every control below is disabled; launch the .exe instead.

How this works

  1. Paste a key into its slot and press Save; it goes straight into the OS credential store (Windows Credential Manager), never into a file.
  2. Verify runs a free live probe (bot identity, fal nil-request, provider model-list). Nothing billable ever runs.
  3. Hand keys to agents with Copy: raw, PowerShell $env:, bash export, or .env line; then paste into Codex, OpenCode, Antigravity, or any terminal.

Status pills show a masked fingerprint (abcd…wxyz) only. Full values are revealed solely by your explicit Reveal / Copy click, auto-hidden after 15 seconds.

Bulk handoff

Copy every saved key as .env lines in one go; paste into a terminal so Codex / OpenCode / Antigravity inherit them all. Clipboard only; nothing is written to disk.
